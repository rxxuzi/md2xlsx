# 文法リファレンス

[English](syntax.md)

`md2xlsx.py` が解釈する Markdown 方言の全文法。全機能を 1 ファイルで使った
例は [`examples/sample.md`](../examples/sample.md)。

## シート

```markdown
#[売上]
...内容...

#[タスク]
...内容...
```

`#[名前]` ごとに新しいシートになる。最初の `#[...]` より前の内容
（あるいは `#[...]` が 1 つもないファイル）は `Sheet1` に入る。シート名は
Excel の制限で 31 文字を超えると切り詰められる。

## ディレクティブ

`#[名前]` の直下に 1 行 1 つ。間に空行があっても構わない。それ以外の場所に
書いた `@...` は普通のテキスト扱い。

| ディレクティブ | 効果 |
|---|---|
| `@freeze(N)` | 上 N 行を固定 |
| `@filter` | 使用範囲にオートフィルタ |
| `@style(A=10, B=30 yellow)` | 列スタイル（後述） |
| `@document` | ドキュメントモード（後述） |

`@filter` は常に `A1` から最後の使用セルまでを範囲にする。テーブルの上に
見出しを置くとそれもフィルタ範囲に入ってしまうので、使うときはテーブルを
シートの先頭に置くこと。

### 列スタイル

`@style` には `列=値` の組をカンマ区切りで並べる。値はスペース区切りで、
CSS のショートハンドのように形で判別される。数値なら列幅、色名か
`#RRGGBB` なら背景色、`bold` / `italic` ならフォント、`left` / `center` /
`right` なら横位置。

```markdown
@style(A=6 center, B=30, D=14 lightyellow bold)
```

指定なしの列は自動幅。ヘッダ行やセルデコレータとの優先順位は
[スタイル](style.ja.md) に。

自動幅は 8〜60 文字幅にクランプされる。全角文字は 2 文字分として数える。

## テーブル

### パイプテーブル

```markdown
| 品目 | 数量 |
|------|------|
| りんご | 3 |
```

`|` を含む行（`#` で始まらないもの）はすべてテーブル行になる。`|---|` の
区切り行は、その **直前の行** をヘッダー（太字・白文字・青背景・中央揃え）
にする。区切り行がないテーブルにはヘッダーがない。空行でテーブルは終わる。

### CSV / TSV テーブル

パイプを書きたくない人向け、Excel からの貼り付けもそのままいける。1 行目が
常にヘッダー。区切りは自動判定（タブがカンマより多ければタブ）、
`table:csv` / `table:tsv` で明示もできる。

````markdown
```table
品目,数量
りんご,3
```
````

引用符の扱いは Python の `csv` モジュール準拠なので、`"a,b"` は 1 セル。

## セルの値

テーブル内でも普通の行でも、すべてのセルに適用される。

| 書く | できる |
|---|---|
| `1200`, `3.14` | 数値 |
| `$$=SUM(B2:B5)$$` | Excel 数式 |
| `$1,200` | `$#,##0` 書式の数値 |
| `¥1,200` | `¥#,##0` 書式の数値（`￥` でも可） |
| `30%` | `0.3` を `0.0%` 書式で |
| `2024-01-15` | 日付セル（`YYYY-MM-DD` のみ） |
| `[表示名](https://...)` | ハイパーリンク（文中でも可） |
| `**太字**` `*斜体*` `` `code` `` | セルのフォントスタイル |

補足:

- 数式はセル全体である必要がある。Excel はテキストと数式を 1 セルに同居
  できないので `合計: $$=SUM(...)$$` はテキストのまま。セルを分けること。
- 数式はそのまま書き込まれるだけで、計算はしない。Excel が開いたときに
  計算する。再計算しないビューア（GitHub のプレビュー、一部のモバイル
  アプリ）では Excel や LibreOffice で開くまで空セルに見えることがある。
- 数式内の行番号はシートの 1 行目から数える。テーブルの上に `##` 見出しを
  置くとテーブルは 1 行下にずれる。
- 通貨記号なしの `1,200` はテキストのまま。`$1,200.50` は `1200.5` として
  保存されるが小数は表示されない。
- セルの型は排他的。数式や通貨のセルには `**太字**` などのインライン
  スタイルが効かず、リンクのセルは数値にならない。
- `` `code` `` の等幅フォントは、セルに太字も斜体もないときだけ効く。

## セル装飾

セルのテキストの先頭に `{キー:値}` を付ける。複数可。

```markdown
| {bg:lightyellow}{comment:2024-02-01開始}設計 | {dropdown:未着手,進行中,完了}進行中 |
```

| タグ | 効果 |
|---|---|
| `{bg:yellow}` | 背景色 |
| `{fg:red}` | 文字色 |
| `{comment:テキスト}` | セルコメント |
| `{dropdown:A,B,C}` | 入力規則のリスト |
| `{align:right}` | `left` / `center` / `right` |

色名: `red green blue yellow orange purple pink gray grey white black
lightblue lightgreen lightred lightyellow`、または `#RRGGBB`。

ドロップダウンの選択肢はカンマ区切りなので、選択肢自体にカンマは使えない。

## 見出しとテキスト

通常モード:

| Markdown | 結果 |
|---|---|
| `## 見出し` | A 列に太字 13pt |
| `### 小見出し` | A 列に太字 11pt |
| 普通の行 | A 列にテキスト |
| `- 項目` / `* 項目` | A 列にテキスト。記号は落とす |
| `1. 項目` | A 列にテキスト。番号は残す |
| `---` | 空行 |

通常モードでは `# 見出し`（`#` 1 つ）は見出しに **ならず**、そのまま文字と
して書き込まれる。`#` は `#[シート]` とドキュメントモード用。

## ドキュメントモード

`@document` を付けると、全セルに罫線が引かれた、いわゆる Excel 仕様書の
レイアウトになる。見出しが構造を作る: `#` の数が列になる（`#` → A、
`##` → B、`###` → C、…）。普通の行と箇条書きが本文で、直前の見出しの
1 つ右の列に入る。箇条書きはスペース 2 つのインデントごとにさらに 1 列
右へ。自動採番はしないので番号は自分で書く。

```markdown
#[基本設計書]
@document

# 1. 機能要件
## 1.1 ログイン機能
ユーザー ID とパスワードでログインする。
- ユーザーIDを入力する
- パスワードを入力する
  - マスク表示
# 2. 非機能要件
## 2.1 パフォーマンス
レスポンス 3 秒以内。
```

| A | B | C | D |
|---|---|---|---|
| 1. 機能要件 | | | |
| | 1.1 ログイン機能 | | |
| | | ユーザー ID とパスワードでログインする。 | |
| | | ユーザーIDを入力する | |
| | | パスワードを入力する | |
| | | | マスク表示 |
| 2. 非機能要件 | | | |
| | 2.1 パフォーマンス | | |
| | | レスポンス 3 秒以内。 | |

`#` と `##` は太字、それより深い見出しと本文は通常の太さ。ドキュメント
モードのシートでもテーブルは使える。A 列から始まり、通常の下罫線の
代わりに全体の罫線が付く。
