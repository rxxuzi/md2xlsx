# スタイル

[English](style.md)

セルの見た目がどう決まるか。`md2xlsx` が勝手に付けるもの、変える方法 3 つ、
重なったときにどれが勝つか。各構文そのものは
[文法リファレンス](syntax.ja.md) に。このページは見た目の話。

## デフォルト

以下で変えない限りすべて Arial 11pt。

| 要素 | 見た目 |
|---|---|
| テーブルヘッダ（`\|---\|` の上の行、または ```` ```table ```` の 1 行目） | 青背景、白の太字、中央揃え |
| テーブル本体の行 | 下に薄いグレーの罫線、上下中央 |
| `##` 見出し | 太字 13pt、左揃え |
| `###` 以降 | 太字 11pt、左揃え |
| ハイパーリンク | 青、下線 |
| `` `code` `` セル | Consolas、暗い赤 |
| ドキュメントモード | 使用セル全体に黒の細罫線、`#` と `##` の行は太字 |
| 列幅 | 最長の値 + 3、8〜60 にクランプ。全角は 2 文字分 |

## 変える方法 3 つ

### 1. インライン Markdown

セル内の `**太字**`、`*斜体*`、`` `code` `` はそのセルのフォントを変える。
型付きセル（数式、`$` / `¥` の金額、パーセント、日付）とリンクを含む
セルではインライン記法は無視され、値のほうが優先される。

### 2. セルデコレータ

セルの先頭に付ける `{bg:…}`、`{fg:…}`、`{align:…}`。（`{comment:…}` と
`{dropdown:…}` は見た目ではないので文法リファレンスを参照。）

```markdown
| {bg:lightyellow}{fg:red}{align:center}注意 |
```

### 3. 列スタイル — `@style`

`#[名前]` の下に 1 行書くと列ごとにまとめてスタイルが付く。`列=値` の
組をカンマ区切りで並べ、値はスペース区切り。CSS のショートハンドのように
値の形で判別するので順番は関係ない。

| 値 | 効果 |
|---|---|
| 数値 | 列幅 |
| 色名または `#RRGGBB` | 背景色 |
| `bold` / `italic` | フォントスタイル。セルが元々持っているものに追加される |
| `left` / `center` / `right` | 横位置 |

```markdown
#[タスク]
@style(A=6 center, B=30, D=14 lightgreen bold)
```

- 列名は大文字小文字を区別しない。`a=6` でも動く。
- 幅は Excel の列全体に効く。背景色・フォント・横位置は使用中の行にだけ
  セル単位で適用される（その列にある普通のテキストや見出しも含む）ので、
  データより下が汚れない。
- 指定なしの列は自動幅。認識できない値は無視される。`@style(A=huge)` は
  何もしない。
- `@style` の色は常に背景色。文字色はセル単位の `{fg:…}` でのみ指定できる。

## 色

`red green blue yellow orange purple pink gray grey white black lightblue
lightgreen lightred lightyellow`、または `#RRGGBB`。色を受け付ける場所は
どこでも同じリスト。

## どれが勝つか

強い順に:

1. **テーブルヘッダの見た目。** ヘッダ行は `@style` の対象外で、ヘッダ
   セルに付けた `{bg:…}` / `{fg:…}` / `{align:…}` も青・白・中央揃えの
   ヘッダスタイルで上書きされる。`{comment:…}` と `{dropdown:…}` は残る。
2. **セルデコレータとインライン Markdown。** `B=yellow` の列にある
   `{bg:red}` のセルは赤のまま、`center` の列にある `{align:left}` は
   左揃えのまま。
3. **列スタイル。** セルが自分で設定していない項目を埋める。
4. **デフォルト。**

列の `bold` / `italic` はセルのフォントを置き換えるのではなく追加なので、
`bold` の列にある `*メモ*` は太字の斜体になる。
